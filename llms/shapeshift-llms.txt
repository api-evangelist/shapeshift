# ShapeShift

> ShapeShift is a community-owned, non-custodial multichain cryptocurrency platform (founded 2014, backed by Earlybird VC, now a DAO). Its open-source "unchained" backend exposes a public, key-free REST + WebSocket API providing a common interface to 40+ blockchains: account/token balances, transaction history, UTXOs, signed-transaction broadcast, gas/fee estimation, and realtime pending/confirmed transaction updates.

## APIs

- [Unchained Ethereum (EVM) API docs](https://api.ethereum.shapeshift.com/docs/): REST for Ethereum & EVM chains (avalanche, bnbsmartchain, optimism, polygon, gnosis, arbitrum, base).
- [Unchained Bitcoin (UTXO) API docs](https://api.bitcoin.shapeshift.com/docs/): REST for Bitcoin & UTXO chains (dogecoin, litecoin, bitcoincash) with UTXO endpoints.
- [Unchained Solana API docs](https://api.solana.shapeshift.com/docs/): REST for Solana with enriched transactions and token details.

## Notes

- Authentication: none — the hosted API is public and key-free over HTTPS.
- Realtime: WebSocket transaction subscriptions (pending + confirmed) per address.
- Errors: custom JSON envelopes (400 {error}, 422 {message,details}, 500 {message}); not RFC 9457.
