ShapeShift is a community-owned, non-custodial multichain cryptocurrency platform where users buy, hold, trade, and earn with digital assets across 48+ blockchains and 10,000+ tokens while retaining full custody of their keys. Its open-source "unchained" backend exposes a public, key-free REST and WebSocket API that provides a common interface to many blockchains — account balances, transaction history, UTXOs, raw transaction broadcast, gas/fee estimation, and realtime pending/confirmed transaction updates — behind per-chain hosts such as api.ethereum.shapeshift.com and api.bitcoin.shapeshift.com. ShapeShift was founded in 2014, is backed by Earlybird Venture Capital, and today operates as a DAO with all code public under github.com/shapeshift.
